# مكتبة القرآن والسنة

برنامج يجمع القرآن الكريم وكتب الحديث وشروحها، والفقه المقارن بأدلته، والقواعد الفقهية، والسيرة النبوية وتاريخ الخلفاء وسير الصحابة. فيه بحث بطرق كثيرة، وخرائط ذهنية، ومحفوظات وهوامش، ومراجعة للحفظ، وآلية للمراجعة العلمية. ويعمل بدون إنترنت.

## التشغيل
- **برنامج سطح المكتب (ويندوز):** نزّل ملف التثبيت `maktaba-sunnah-setup-*.exe` من تبويب **Actions** (آخر تشغيل ناجح ← Artifacts)، أو من **Releases**.
- **من المتصفح مباشرة:** افتح `index.html` بمتصفح Chrome أو Edge.

أول تشغيل يثبّت المكتبة المدمجة الموجودة في مجلد `data`.

## بناء نسخة سطح المكتب
- **تلقائياً:** GitHub Actions بيبني ملف التثبيت مع كل تحديث على `main` (الملف `.github/workflows/desktop.yml`).
- **يدوياً:** `npm install` وبعدها `npm run dist`، والناتج في مجلد `dist/`.
- **للتجربة:** `npm start`.

التفاصيل الكاملة في [دليل-البرنامج.md](دليل-البرنامج.md).

## هيكل المستودع
| المسار | المحتوى |
|---|---|
| `index.html`, `css/`, `js/` | البرنامج |
| `desktop/`, `package.json`, `build/` | غلاف سطح المكتب (Electron) والأيقونة |
| `data/` | المكتبة المدمجة: القرآن، و17 كتاب حديث بأحكام المحدثين، وملف المراجعة المنشورة `review.js` |
| `scripts/build_pack.py` | يبني القرآن وكتب الحديث في `data/` |
| `scripts/build_books.py` | يبني الشروح والتفاسير وكتب الفقه والسيرة من نصوص OpenITI، ويربطها بالأحاديث والآيات |
| `scripts/build_catalog.py` | يبني فهرس كتب التراث (12 ألف كتاب) للبحث والتحميل |
| `scripts/build_curriculum.py` | يبني منهج طلب العلم ويربط متونه بالمكتبة والفهرس |
| `scripts/test_*.py` | اختبارات آلية في المتصفح |

## المصادر
- نص القرآن الكريم: [مشروع تنزيل](https://tanzil.net). يُذكر المصدر ولا يُعدَّل النص.
- الكتب الستة والموطأ والأربعينات مع أحكام المحدثين: [hadith-api](https://github.com/fawazahmed0/hadith-api).
- الشروح والتفاسير وكتب الفقه والسيرة وفهرس الكتب: [OpenITI](https://github.com/OpenITI) عن المكتبة الشاملة.
- باقي كتب الحديث: [hadith-json](https://github.com/AhmedBaset/hadith-json)، المأخوذ من sunnah.com.
